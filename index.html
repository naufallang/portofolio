Data tool, personal project

DataGlance

A browser tool that profiles any CSV file in seconds. It detects column types, computes summary statistics, and charts distributions and relationships, so you understand a dataset before writing analysis code.

  • Type detection for numeric, categorical, date, and text columns
  • Mean, median, standard deviation, missing values, and outliers (1.5 × IQR) per column
  • Pearson correlation heatmap that calls out strongly related pairs
  • Scatter plot with color grouping and a sortable data preview
  • Runs entirely in the browser, so files are never uploaded
Built with
  • JavaScript
  • SVG charts
  • Statistics
  • CSV parsing

Rekam Tumbuh

An app that helps parents track the growth of children aged 0 to 5. The idea came from interviews: parents said online parenting advice is contradictory and tracking immunizations by hand is hard.

  • Growth charts for weight, height, and head size against WHO standards
  • Reminders for immunizations and health check-ups
  • A daily journal for activities and milestones
  • Parenting tips from experts and consultations with doctors

Web app, personal project

QuizByte

A timed multiple-choice quiz for computer science students on programming, data science, and web development. Every answer comes with a short explanation, so it works as a study tool, not just a test.

  • Three topics plus a mixed set drawn from all of them
  • 20-second timer with points for speed and answer streaks
  • Results with accuracy, average answer time, and a full review
  • Best score saved per topic, keyboard shortcuts, and dark mode
