02 of 05, CSV profiling tool

DataGlance.

A browser tool that profiles any CSV file in seconds, before you write a single line of analysis code.

Exploring a new dataset usually starts with the same steps: check the columns, look for missing values, and see how variables relate to each other. DataGlance does those steps automatically for any CSV file.

Parsing, type detection, statistics, and charts are written in plain JavaScript without libraries. Everything runs in the browser, so the data never leaves the user's computer.

Key features

  • Type detection for numeric, categorical, date, and text columns
  • Mean, median, standard deviation, missing values, and outliers (1.5 × IQR) per column
  • Pearson correlation heatmap that calls out strongly related pairs
  • Scatter plot with color grouping and a sortable data preview
  • Handles comma, semicolon, and tab separated files
