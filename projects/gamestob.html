03 of 05, Game store website

gameStoB.

A digital game store where players browse, compare, and buy games and DLC.

gameStoB is a concept store for buying games and DLC. I designed every page in Figma before writing any code, then built the site with plain HTML, CSS, and JavaScript.

The catalog and checkout are driven by JavaScript: filters, search, and sorting update the game grid instantly, and the checkout form checks every field before an order can be placed.

Type
Multi-page website, designed in Figma
Built with
  • HTML
  • CSS
  • JavaScript
  • Figma
Links
Open live site

Key features

  • Five pages: home, catalog, checkout, about, and store locations
  • Catalog of 22 games and DLC with genre filters, live search, and sorting
  • Checkout with a live order summary and validation on every field
  • Store location concepts linked to Google Maps
  • Responsive layout with a slide-out mobile menu
